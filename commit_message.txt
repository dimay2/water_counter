- **Gemini API Interaction:**
  - Refactored `call_gemini_with_retry` in `gemini_utils.py` for dynamic model selection and demotion upon failure, ensuring subsequent retries use a different, higher-ranked model.

  - Ensured all function calls across `meter_extractor.py`, `pdf_extractor.py`, and `water_counter_to_sheets.py` align with updated function signatures (e.g., passing `profiles` argument, removing `model_name` from `call_gemini_with_retry`).

- **Removed Complex Font Formatting:**
